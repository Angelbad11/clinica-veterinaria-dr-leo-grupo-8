# Notas de entrega

El proyecto Clinica Veterinaria Dr Leo incluye un modulo funcional en Python con interfaz grafica Tkinter.

Flujo principal:
1. Registro de propietarios
2. Registro de mascotas
3. Gestion de citas
4. Registro de consultas
5. Registro de pagos
6. Historial clinico
7. Recordatorios
8. Reportes

Los datos personales se protegen evitando mostrar DNI y celular completos en la interfaz y en los reportes.
